A one-line roast of the gadget I wear every day: my smartwatch, which congratulates me for standing up and then, two minutes later, reminds me to breathe — as if standing was the achievement and breathing is the sequel it doesn't trust me to survive alone. The program writes that single line to entry.txt in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
